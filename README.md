#  ANS - Sztuczna Inteligencja (Laboratoria)

To miejsce służy jako centralny zbiór moich rozwiązań i projektów realizowanych w ramach zajęć laboratoryjnych z przedmiotu **Sztuczna Inteligencja**.

Wszystkie znajdujące się tutaj pliki (głównie skrypty w języku Python oraz notatniki `.ipynb` Jupyter/Google Colab) stanowią odpowiedź na zadania stawiane podczas poszczególnych etapów laboratoriów.

##  Cel Repozytorium

Repozytorium ma charakter akademicki i zostało utworzone w celu:
* Zbierania ukończonych zadań w uporządkowanej formie.
* Udostępniania kodów źródłowych do oceny i sprawdzenia przez prowadzącego zajęcia.
* Monitorowania własnych postępów w nauce algorytmów SI oraz sieci neuronowych.

##  Technologie
Projekty w tym repozytorium opierają się na standardowych narzędziach wykorzystywanych w uczeniu maszynowym, takich jak:
* `Python`
* `TensorFlow` / `Keras`
* `NumPy`
* `Scikit-learn`
* `Matplotlib` / `Seaborn` (do wizualizacji)
